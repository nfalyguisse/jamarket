# Technical Competency Framework - Jamarket

This document lists all competencies for Bloc 2 (Development) and Bloc 4 (Maintenance).
Cursor must ensure the codebase reflects these requirements.

## BLOC 2: Design & Development (Applications Software)

| ID         | Competency Description                                                         | Eliminatory |
| :--------- | :----------------------------------------------------------------------------- | :---------- |
| C2.1.1     | Implement deployment and test environments with performance/quality tools.     | NON         |
| C2.1.2     | Configure CI (Continuous Integration) to merge code and test blocks regularly. | NON         |
| **C2.2.1** | **Design a prototype (Web/Mobile) respecting ergonomics and security.**        | **OUI**     |
| **C2.2.2** | **Develop a Unit Testing harness to prevent regressions.**                     | **OUI**     |
| **C2.2.3** | **Develop software with focus on scalability, security, and accessibility.**   | **OUI**     |
| C2.2.4     | Deploy software progressively and verify performance with users.               | NON         |
| **C2.3.1** | **Create test scenarios and UAT (cahier de recettes) to detect anomalies.**    | **OUI**     |
| C2.3.2     | Create a bug correction plan based on UAT results.                             | NON         |
| C2.4.1     | Write technical documentation for software exploitation and traceability.      | NON         |

## BLOC 4: Maintenance & Operational Conditions

| ID         | Competency Description                                                         | Eliminatory |
| :--------- | :----------------------------------------------------------------------------- | :---------- |
| C4.1.1     | Manage updates for dependencies and 3rd party libraries (Security monitoring). | NON         |
| **C4.1.2** | **Design a supervision and alerting system (monitoring indicators).**          | **OUI**     |
| **C4.2.1** | **Log detected anomalies and establish a collection process.**                 | **OUI**     |
| C4.2.2     | Create and deploy patches using CI/CD processes.                               | NON         |
| C4.3.1     | Propose improvements based on performance and user feedback.                   | NON         |
